# Integer

## Description

Représente une valeur numérique entière signée (par ex : `42`, `-157`,...)

Une valeur décimale égale à un entier (à 1e-7 près) est acceptée (par ex : `42.0`).

## Mapping

| Langage    | Type      |
| ---------- | --------- |
| Java       | `Integer` |
| JSON       | `number`  |
| PostgreSQL | `integer` |
